# Changelog

## Release Version 1.1.0 (Fabric, NeoForge 1.21.1)

- Added a public mod-developer API under `com.jvn.emeraldpouch.api` for detecting pouches, reading contents, and safely updating player-held pouch stacks.
- Added configurable pouch indicator presets for inventory and villager screens.
- Added equip sound support for Accessories, Curios, and Trinkets integration paths.
- Improved pouch interaction behavior and refreshed the README with updated controls and API notes.
